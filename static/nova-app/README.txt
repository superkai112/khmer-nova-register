KHMER NOVA PWA

After this folder is deployed with the existing Flask app, open:
https://YOUR-RENDER-DOMAIN/static/nova-app/index.html

The app uses the existing same-origin /api/register and /api/login endpoints.
It does not change the existing homepage, database, or ROS Legacy game binary.
For iPhone: open the URL in Safari, tap Share, then Add to Home Screen.
For Android: open in Chrome and choose Install app / Add to Home screen.
